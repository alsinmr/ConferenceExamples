# <font color=#A80000> Andy's Conference Tutorials </font>

This is a collection of tutorials that I have prepared for various NMR conferences and schools. I have started collecting these tutorials into a webpage as of 2025, but older examples may be found in the GitHub repository [link](https://github.com/alsinmr/ConferenceExamples). Also check out our software packages, [SLEEPY](http://sleepy-nmr.org) and [pyDIFRATE](https://alsinmr.github.io/pyDR).
